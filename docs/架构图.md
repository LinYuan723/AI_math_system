## 数据流图

```mermaid
flowchart LR
    classDef input fill:#BBDEFB,stroke:#1565C0,stroke-width:2px,color:#0D47A1
    classDef process fill:#C8E6C9,stroke:#2E7D32,stroke-width:2px,color:#1B5E20
    classDef output fill:#FFE0B2,stroke:#E65100,stroke-width:2px,color:#BF360C

    IN1[📥 上传成绩Excel]:::input --> P1[成绩解析<br/>数据校验]:::process
    P1 --> DB[(SQLite)]:::input
    
    IN2[📷 拍摄错题照片]:::input --> P2[OCR文字提取<br/>AI结构化识别]:::process
    P2 --> DB
    
    IN3[⚙️ 配置出题要求]:::input --> P3[逐题调用AI<br/>生成试卷]:::process
    P3 --> DB

    DB --> P4[数据统计<br/>AI分析诊断]:::process
    P4 --> OUT1[📊 可视化报告<br/>雷达图 · 趋势图]:::output
    P4 --> OUT2[📋 AI分析报告<br/>诊断 · 建议 · 评语]:::output
    P4 --> OUT3[📄 Word/PDF导出<br/>学生版 · 教师版]:::output
```
