# 初中数学智能信息系统

基于 DeepSeek 大模型的初中数学智能教学辅助平台。利用 AI 技术帮助数学教师高效完成学情分析、错题辅导和试卷生成工作。

## AI 如何帮助数学教学？

### 解决的痛点

| 痛点 | 传统方式 | AI 方式 |
|------|----------|---------|
| 成绩分析费时 | 教师手工统计分数、画图表，一份试卷分析耗时 1-2 小时 | 上传 Excel，AI 自动分析，生成可视化报告，**仅需 1 分钟** |
| 错题辅导低效 | 学生错了题，教师无法一对一讲解，家长不会教 | 拍照上传错题，AI 自动识别题目内容，生成学习计划与复习提醒 |
| 出题组卷困难 | 手动翻书找题、拼凑试卷，费时且难以匹配知识点 | 选择知识点+难度+题型，AI 自动生成试卷并导出 Word，**5 分钟出卷** |
| 学情追踪缺失 | 凭感觉判断学生掌握情况，缺乏数据支撑 | AI 分析历次考试数据，自动生成雷达图、趋势图，精准定位薄弱知识点 |

### AI 实现的功能

**学情智能分析** 使用的 AI 能力：
- 🧠 **班级整体诊断**：AI 解读全班成绩分布，总结整体优劣势
- 🔍 **薄弱知识点定位**：自动识别班级共性薄弱点，给出针对性教学建议
- ⭐ **学生分层评价**：自动识别优秀学生和需关注学生
- 📈 **个人学情追踪**：AI 分析学生历次考试成绩趋势，生成学期综合评语
- 📄 **报告自动导出**：分析结果一键导出为 Word 或 PDF

**错题智能辅导** 使用的 AI 能力：
- 📷 **OCR + AI 题目识别**：拍照上传错题，先通过 OCR 提取文字，再由 AI 整理成结构化题目信息（知识点、题型、题目内容、学生答案、正确答案）
- 📊 **错题统计可视化**：按知识点、错误类型自动生成饼图和柱状图
- 📋 **个性化学习计划**：AI 根据学生错题记录，生成每周学习目标、每日复习安排、资源推荐
- ⏰ **智能复习提醒**：基于艾宾浩斯遗忘曲线，在 1/3/7/14/30 天提醒复习

**智能出题组卷** 使用的 AI 能力：
- 📝 **按需生成题目**：指定知识点、难度（1-5星）、题型（选择/填空/解答）、数量，AI 自动生成
- 📐 **知识点精准匹配**：覆盖湖北省天门市中考数学全部知识点分类（数与代数、空间与图形、统计与概率、综合与实践）
- 📋 **试卷组装导出**：多组题目前后排序、一键导出教师版（含解析）和学生版（纯题目）Word 文档
- ⚡ **逐题生成+实时计时**：每道题单独生成，实时显示进度和耗时，支持终止

## 如何从零开始运行本项目

如果你是第一次接触 Python，请严格按照以下步骤操作。

推荐使用 **Anaconda**（方式一），它能自动管理 Python 版本和依赖，避免环境冲突，对新手更友好。

---

### 选择你的安装方式

#### 方式一：使用 Anaconda 管理环境（推荐）

Anaconda 是一个 Python 环境管理工具，可以帮你自动配置 Python 环境，避免版本冲突。

**1. 安装 Anaconda**

- 打开浏览器，访问 https://www.anaconda.com/download
- 下载对应系统的安装包（Windows 用户选择 `.exe` 文件）
- 双击安装包，一路点击 "Next" 完成安装
- 安装完成后，在开始菜单中找到 **Anaconda Prompt**（一个黑色窗口），打开它

**2. 下载本项目**

- 打开 https://github.com/LinYuan723/AI_math_system
- 点击绿色按钮 "Code"，选择 "Download ZIP"
- 将下载的 ZIP 文件解压到你想要的文件夹（如桌面）
- 或者如果你会使用 Git，在 Anaconda Prompt 中输入：
  ```bash
  git clone https://github.com/LinYuan723/AI_math_system.git
  ```

**3. 创建虚拟环境**

在 Anaconda Prompt 中，进入项目文件夹（包含 `APP.py` 的文件夹）：
```bash
cd 你的项目文件夹路径
```
例如解压在桌面：
```bash
cd C:\Users\你的用户名\Desktop\AI_math_system
```

然后创建一个独立的 Python 环境：
```bash
conda create -n ai_math python=3.10
```
出现提示时输入 `y` 并回车确认。

**4. 激活环境并安装依赖**

```bash
conda activate ai_math
```
激活后，命令提示符前面会出现 `(ai_math)` 标识。然后安装项目依赖：
```bash
pip install -r requirements.txt
```
等待安装完成（可能需要 3-5 分钟）。

> **每次使用项目前**，都需要先打开 Anaconda Prompt，进入项目文件夹，执行 `conda activate ai_math` 激活环境，然后才能运行项目。

---

#### 方式二：手动安装 Python

如果你不想安装 Anaconda，也可以直接安装 Python。

**1. 安装 Python**

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击黄色按钮 "Download Python 3.x.x" 下载安装包
3. 双击下载的安装包
4. **重要：勾选底部的 "Add Python to PATH"**（一定要勾选！）
5. 点击 "Install Now" 完成安装
6. 验证安装：按 `Win + R`，输入 `cmd` 回车，在黑色窗口中输入：
   ```
   python --version
   ```
   如果显示 `Python 3.x.x` 说明安装成功。

**2. 下载本项目**

1. 打开 https://github.com/LinYuan723/AI_math_system
2. 点击绿色按钮 "Code"，选择 "Download ZIP"
3. 将下载的 ZIP 文件解压到你想要的文件夹（如桌面）
4. 或者如果你会使用 Git：
   ```bash
   git clone https://github.com/LinYuan723/AI_math_system.git
   ```

**3. 安装依赖**

1. 打开项目文件夹（包含 `APP.py` 的那个文件夹）
2. 在文件夹地址栏输入 `cmd` 并回车，打开命令提示符
3. 在命令提示符中输入以下命令安装项目依赖：
   ```bash
   pip install -r requirements.txt
   ```
4. 等待安装完成（可能需要 3-5 分钟，取决于网速）。如果出现红色报错，请检查网络连接后重试。

### 配置 DeepSeek API 密钥（两种方式通用）

AI 功能需要调用 DeepSeek 大模型，你需要一个 API 密钥：

1. 访问 https://platform.deepseek.com/ 注册账号
2. 在控制台中找到 "API Keys"，点击 "创建 API Key"
3. 复制生成的密钥（格式如 `sk-xxxxxxxx`）
4. 在项目文件夹中，找到 `.env` 文件（如果没有，新建一个文本文件命名为 `.env`）
5. 用记事本打开 `.env`，填入以下内容：
   ```
   DEEPSEEK_API_KEY=你的API密钥
   DEEPSEEK_BASE_URL=https://api.deepseek.com
   ```
   将"你的API密钥"替换为你第 3 步复制的真实密钥。
6. 保存文件。

> ⚠️ **重要**：API 调用会产生费用（约 1-2 元/百万 token）。一个班级的成绩分析大约消耗几分钱。建议先充值 10 元测试使用。

### 生成示例数据（可选，推荐）

如果你还没有真实的学生成绩数据，可以先运行示例数据生成脚本来体验系统：
```bash
python demo/create_sample_data.py
```
这会在 `data/` 文件夹下生成一个示例 Excel 文件，可以直接用于测试学情分析功能。

### 启动应用

在命令提示符中输入：
```bash
streamlit run APP.py
```

等待几秒，浏览器会自动打开 `http://localhost:8501`，你就可以开始使用了。

### 停止应用

在命令提示符中按 `Ctrl + C` 即可停止应用。

## 使用指南

### 学情智能分析

1. 点击左侧导航「📊 学情智能分析」
2. 切换到「📤 上传成绩」标签页
3. 上传符合格式的成绩 Excel 文件（需要包含"考试信息"、"题目信息"、"学生成绩"三个 Sheet，具体格式可参考 `demo/create_sample_data.py` 生成的示例）
4. 点击「💾 保存成绩」存入数据库
5. 切换到「🤖 AI分析」标签页，选择考试，点击「启动AI深度分析」
6. AI 会生成班级整体情况、薄弱知识点、教学建议、优秀学生和需关注学生名单
7. 可导出为 Word 或 PDF 报告
8. 切换到「👤 个人学情」标签页，选择学生查看个人成绩趋势和 AI 综合评语

### 错题智能辅导

1. 点击左侧导航「📝 错题智能辅导」
2. 在顶部选择或输入学生信息
3. **录入错题**：上传错题照片 → 点击「AI识别题目」→ 检查/修改识别结果 → 保存
4. **错题本**：查看该学生所有错题，可按知识点筛选，查看错误分布图表
5. **学习诊断**：点击「AI生成学习计划」获取个性化学习方案；查看智能复习提醒

### 智能出题组卷

1. 点击左侧导航「📄 智能出题组卷」
2. 输入试卷标题
3. 选择知识类别 → 知识点 → 难度 → 题型 → 数量，点击「添加到试卷」
4. 可添加多组不同配置的题目
5. 点击「AI生成试卷」开始逐题生成
6. 生成完成后可查看每题解答，支持导出试卷版（学生用）和解析版（教师用）Word 文档

## 技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | Streamlit 1.57 | 纯 Python 构建 Web 界面 |
| AI 模型 | DeepSeek（API） | 成绩分析、题目识别、出题、评语生成 |
| OCR | RapidOCR（onnxruntime） | 离线 OCR，无需联网 |
| 数据库 | SQLite | 轻量级本地数据库，无需安装 |
| 可视化 | Plotly | 交互式图表（雷达图、趋势图、分布图等） |
| 文档导出 | python-docx / fpdf2 | Word 和 PDF 格式导出 |

## 常见问题

**Q：提示"DeepSeek API 未配置"？**
A：检查 `.env` 文件是否存在，密钥是否正确。注意 Windows 可能隐藏 `.env` 文件的扩展名。

**Q：OCR 识别不准？**
A：确保图片清晰，文字可辨。手写字体的识别率低于印刷体。如果完全无法识别，可以手动填写题目信息。

**Q：API 调用失败？**
A：检查网络连接；确认 API 密钥未过期；确认 DeepSeek 账户余额充足。

**Q：如何更新依赖？**
A：在项目目录中运行 `pip install -r requirements.txt --upgrade`。
